# Front-API-SEMESTRE3

Este é o projeto frontend desenvolvido com **Vite.js**, utilizando **Tailwind CSS** para estilização e **ShadCN UI** para componentes de interface. O projeto serve como base para consumir dados de uma API e exibir a interface de forma rápida e reativa.

## Tecnologias Utilizadas

- **Vite.js**: Ferramenta de build moderna para desenvolvimento de aplicações JavaScript.
- **Tailwind CSS**: Framework de CSS para construção de interfaces responsivas e personalizáveis.
- **ShadCN UI**: Conjunto de componentes UI para criar interfaces interativas de maneira rápida e com boas práticas de design.
- **Axios**: Para realizar as requisições HTTP para a API.
- **React.js** (ou outra biblioteca/framework de sua escolha)
- **React Router**: Para navegação entre páginas (se estiver utilizando React).

## Pré-requisitos

Antes de rodar este projeto localmente, você precisará ter as seguintes ferramentas instaladas:

- [Node.js](https://nodejs.org/) (versão LTS recomendada)
- [npm](https://www.npmjs.com/) ou [Yarn](https://yarnpkg.com/) (gerenciadores de pacotes)

## Instalação

### 1. Clonar o Repositório

Primeiro, clone o repositório para sua máquina local:

```bash
git clone https://github.com/equipeAdalove/Front-API-SEMESTRE3.git
cd Front-API-SEMESTRE3
```

### 2. Instalar as Dependências

```bash
npm install
```

### 3. Rodando o Projeto

```bash
npm run dev
```
